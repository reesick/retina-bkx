# 03 · ML

All code is in `ml/`. Every stage is seeded (42) and resumable. `python -m ml.run_all` runs everything in order.

## Datasets (downloaded by `ml/data/fetch.py`)

| Dataset | Source used | Licence | Size used | Role |
|---|---|---|---|---|
| APTOS 2019 (Aravind, India) | HF mirror `sngsfydy/aptos` (parquet) | Kaggle competition rules (not redistributed) | 3,662 graded | Train / validate / internal test of graders |
| IDRiD (Nanded, India) | HF mirror `MahsaTorki/IDRiD_Dataset` (official zips) | CC-BY 4.0 | 516 graded + OD/fovea centres; 81 lesion-annotated | External grading test; landmarks; lesion seg; demo cases |
| DDR (China, multi-site) | HF mirror `ctmedtech/DDR-dataset` | CC-BY 4.0 | 4,105 test graded (incl. grade 5 = ungradable); 757 lesion-annotated | External grading test; quality test; lesion seg |
| DeepDRiD | GitHub `deepdrdoc/DeepDRiD` (sparse checkout, regular fundus) | CC-BY-SA 4.0 | 2,000 images, quality labels, patient ids | Real quality labels (train for M1, val for evaluation); laterality check |

Every image is converted once by `core.fundus.crop_square` (crop to the fundus disc, pad to a centred square,
resize) to 768 px (grading, landmarks, quality) or 1024 px (lesions). Raw downloads are deleted after conversion.

## Splits and leakage rules

- APTOS: stratified 70 / 15 / 15 (train / val / test), seed 42, image-level because APTOS has no patient ids
  (`data/splits/aptos.csv`). Val is the only set used for temperature scaling, OOD fitting and every policy threshold.
- IDRiD and DDR test never touch grader training or thresholds. IDRiD train is used for landmark training (selected
  on a 15% hold-out of IDRiD train) and lesion training; IDRiD test is used to report landmark and lesion results.
- DeepDRiD: official train / validation split (patient level). Train feeds the quality model; validation is held out.

## Models

| ID | Model | Input | Data | Recipe | ONNX outputs |
|---|---|---|---|---|---|
| M1 | EfficientNet-B0 (timm `efficientnet_b0.ra_in1k`) | 384 | DeepDRiD train real labels (×2) + APTOS/IDRiD train with on-the-fly synthetic degradations (blur, motion, dark, glare, shift, haze, noise; none / mild / severe → adequate / usable / inadequate) | 8 epochs, AdamW 1e-3, one-cycle, label smoothing 0.05; selected on fixed synthetic degradations of APTOS val | `logits[1,3]` |
| M2a | EfficientNet-B3 (`efficientnet_b3.ra2_in1k`) | 512 | APTOS train | 16 epochs, AdamW 3e-4 (head 1e-3), cosine with warm-up, sqrt class weights, flips + 360° rotation + colour + blur/noise, AMP; selected on val AUROC(referable) + 0.5·QWK | `logits[1,5]`, `features[1,1536]`, `cam[1,5,16,16]` |
| M2b | DINOv2 ViT-B/14 (`vit_base_patch14_dinov2.lvd142m`, Apache-2.0) | 448 | APTOS train | last 4 blocks + norm + head trainable, 10 epochs, AdamW 4e-5 (head 1e-3) | `logits[1,5]`, `features[1,768]`, `attn[1,32,32]` |
| M3 | U-Net, EfficientNet-B3 encoder, scSE decoder (smp) | 1024 (trained on 512 crops) | IDRiD train 54 + DDR train 383 | 40 epochs, BCE (pos-weight MA 20, others 5) + soft Dice, lesion-biased crops; per-class thresholds Dice-optimal on DDR val | `probs[1,4,1024,1024]` (MA, HE, EX, SE) |
| M4 | U-Net, ResNet-34 encoder → 2 heat-maps | 512 → 128 | IDRiD train 413 (OD + fovea centres) | 60 epochs, Gaussian targets σ = 2.5 cells, flips/rotation/scale/brightness, BCE pos-weight 30 | `heatmaps[1,2,128,128]` |

Explanation maps are computed inside the ONNX graphs so the CPU runtime needs no gradients:
- CNN CAM: for a global-average-pool + linear head, Grad-CAM equals `ReLU(Σ_k W_ck A_k)` exactly. The server shows the
  referable-weighted CAM `Σ_{c≥2} p_c CAM_c / Σ_{c≥2} p_c`.
- ViT: CLS-to-patch attention of the last block, averaged over heads.

## Reliability layer (`ml/eval/evaluate.py`)

1. Temperature scaling per grader on APTOS val (bounded NLL minimisation).
2. Ensemble = mean of calibrated probabilities. P(referable) = P(grade ≥ 2).
3. OOD: PCA-64 of CNN pooled features fitted on APTOS train, Mahalanobis distance; threshold = 99th percentile on val.
4. Operating point `t_refer`: highest threshold with val sensitivity ≥ 0.90.
5. Abstention: `t_disagreement` = 95th percentile of |P_ref(CNN) − P_ref(ViT)| on val; `t_entropy` = smallest cut-off
   where accepted val cases reach sensitivity ≥ 0.95 while abstaining on ≤ 20%.
6. Suspicious-lesion thresholds: 97th percentile of lesion-candidate HE/EX area and HE count among val grade 0–1.
7. Quality rule thresholds (`ml/train/quality.py::fit_rules`): soft = 2nd / 98th percentile on adequate images
   (APTOS train + DeepDRiD good), hard = a fixed fraction of soft.
8. Laterality rule: measured on DeepDRiD file names (`_l` / `_r`) by `ml/eval/extras.py`, not assumed.

All of these, with their provenance strings, are written to `server/models/policy.json` and shown in the UI.

## Evaluation (`ml/eval/evaluate.py`, `ml/eval/extras.py` → `server/models/metrics.json`)

Per model (CNN, ViT, ensemble) and per dataset (APTOS val, APTOS test, IDRiD, DDR, DeepDRiD val): AUROC with
bootstrap 95% CI, sensitivity and specificity at the operating point with CIs, PPV, NPV, QWK, ECE before / after
temperature scaling, Brier, per-grade recall, 5×5 confusion, reliability bins, ROC points.
Triage simulation with the real `core.policy`: coverage (auto-decided share), sensitivity / specificity on
auto-decided cases, referral / human-review / retake / routine rates, referable cases routed ROUTINE (safety count),
risk–coverage curve, OOD flag rate, DDR ungradable images not cleared as routine.
Quality: DeepDRiD val real labels (AUROC for inadequate, poor flagged, good rejected); DDR ungradable.
Lesions: Dice per type on IDRiD test and DDR test. Landmarks: IDRiD test error in disc diameters.
Explanations: pointing game vs area baseline (IDRiD expert masks), deletion test vs random occlusion, model-
randomisation Spearman correlation. Latency p50 / p95 of the full CPU pipeline and a determinism check.

## Export

`ml/export/to_onnx.py` exports opset 17, checks PyTorch-vs-ONNX max absolute difference, and writes
`server/models/manifest.json` with each file's SHA-256 prefix (shown as model versions in every result).

## Honesty rules

No number is shown in the UI unless it is in `metrics.json`. Failures are reported. External sets are called
"external public-dataset evaluation", never clinical validation. The APTOS split is image-level and that is stated.
